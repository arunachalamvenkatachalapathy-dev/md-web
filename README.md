## 💻 Tech Stack & Architecture

- **Runtime & Bundler:** [Bun](https://bun.sh) + [Vite](https://vitejs.dev)
- **UI Framework:** Vanilla Corporate FinTech HTML/CSS/JS + [React 18](https://react.dev)
- **Styling:** Custom 3D Isometric CSS Engine + [Tailwind CSS](https://tailwindcss.com)
- **Typography:** Google Fonts `Plus Jakarta Sans` (100% across display, headings, and telemetry)
- **Static Server:** `serve.js` (Bun native HTTP server on port 5173)

## ⚡ Development & Deployment

```bash
# 1. Install dependencies
bun install

# 2. Run local development server
bun run serve.js
# Or with Vite
bun run dev

# 3. Build production bundle
bun run build
# Bundle React Video Hub
bun build ./src/videoFeedMount.jsx --outfile=assets/video-feed.js --minify
```
